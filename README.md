# FindIt — Campus Lost & Found

Post what you lost or found on campus, search, and claim an item by answering the finder's question.

- `backend/`: Flask + SQLite API (`python -m backend.app`)
- `frontend/`: React (Vite) screens
- `tests/`: pytest, run by GitHub Actions on every push

This repository is sample data for TeamPulse (a student team's project, simulated).
